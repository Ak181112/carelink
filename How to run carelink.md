# CareLink+ — How to Run the Project


## Step 1 — Install Dependencies

Open **two terminals** in the project root folder.

**Terminal 1 — Backend:**
```
cd backend
npm install
npm run dev
```

**Terminal 2 — Frontend:**
```
cd frontend
npm install
npm run dev
```

---

## Step 2 — Open in Browser

```
http://localhost:3000
```

---


## Troubleshooting

**Backend not starting?**
- Make sure you are inside the `backend` folder
- Run `npm install` first

**Frontend not starting?**
- Make sure you are inside the `frontend` folder  
- Run `npm install` first

**Login not working?**
- Make sure both backend (port 5000) and frontend (port 3000) are running at the same time
